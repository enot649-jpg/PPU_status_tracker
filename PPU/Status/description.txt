Проект: Status

Используемый стек: Python 3.10, DjangoRestFramework, Pandas, SQLite

Описание: Приложение Status разработано в рамках программы подачи предложений по улучшению работы предприятия и
предназначено для оперативной актуализации статусов и платежей реализуемых инвестиционных мероприятий, 
а также этапов согласования поданных инвестиционных заявок.
При условии согласования внедрения данного приложения в рабочий процесс предприятия, финальный вариант 
приложения будет направлен в Управление по Информационным технологиям для согласования и последующей 
интеграции в информационный портал предприятия.

Приложение представляет из себя базу данных SQL, хранящую несколько таблиц с данными о мероприятиях,
департаментах, подразделениях  и истории изменения мероприятий, а также набор интернет страниц (Главная 
страница, вспомогательные страницы редактирования и удаления обьектов из базы данных), страницу истории
изменения статуса мероприятия и оплат по нему, форму добавления нового обьекта в базу, а также страницу
администратора.

Для приложения также написаны тесты (Unittest) и создан API на базе DjangoRestFramework, необходимый для 
упрощения процесса интеграции приложения в существующую систему.

Алгоритм подготовки приложения к использованию:
1. При помощи вспомогательной программы import.py или другими способами внести в базу данных SQL сведения
о реализуемых мероприятиях и поданных инвестиционных заявках.
2. При необходимости отредактировать данные (например изменить ответственное за реализацию подразделение) 
силами администратора или пользователя (например сотрудника Управадения по инновационному развитию и 
операционной эффективности)

Алгоритм использования приложения: 
1. После того как приложение будет готово к использованию, сотрудник УИРиОЭ в начале каждой рабочей недели
должен выбрать мероприятия, статус которых необходимо актуализировать и изменить значение в столбце needs_act
на 'Да', а также внести новые платежи по реализуемым проектам и при необходимости поменять департамент 
согласования.
2. Ответственный за заполнение сотрудник структурного подразделения должен найти список требующих актуализацию 
мероприятий используя фильтры (Подразделение, Департамент, Необходимо Актуализировать) и используя кнопку 
'Изменить' внести актуальный статус.
3. Сотрудники могут при необходимости вывести данные в Excel формат для редактирования/печати.
