Проект: Status

Используемый стек: 
-Python 3.12;
-Django, DjangoRestFramework;
-Pandas;
-PostgreSQL;
-Docker, Docker Compose.

Описание: Приложение Status разработано в рамках программы подачи предложений по улучшению работы предприятия и
предназначено для оперативной актуализации статусов и платежей реализуемых инвестиционных мероприятий, 
а также этапов согласования поданных инвестиционных заявок.

Приложение представляет из себя базу данных, хранящую несколько таблиц с данными о мероприятиях,
этапах согласования, подразделениях  и истории изменения статуса мероприятий, а также набор интернет страниц 
(главная страница, вспомогательные страницы редактирования и удаления обьектов из базы данных), страницу истории
изменения статуса мероприятия и оплат по нему, форму добавления нового обьекта в базу, а также страницу
администратора.

Для приложения также написаны тесты (Unittest) и создан API на базе DjangoRestFramework, необходимый для 
упрощения процесса интеграции приложения в существующую систему. Реализована контейнеризация при помощи Docker.

Для подготовки приложения к использованию необходимо внести в базу данных необходимые сведения
о реализуемых мероприятиях и поданных инвестиционных заявках.

Алгоритм использования приложения: 
1. После того как приложение будет готово к использованию, сотрудник УИРиОЭ в начале каждой рабочей недели 
(или по необходимости) должен выбрать мероприятия, статус которых необходимо актуализировать и изменить 
значение в столбце 'Необходима актуализация' на 'Да', а также внести новые платежи по реализуемым проектам 
и при необходимости поменять департамент согласования.
2. Ответственный за заполнение сотрудник структурного подразделения должен найти список требующих актуализацию 
мероприятий используя фильтры (Подразделение, Стадия реализации, Необходимо Актуализировать) и используя кнопку 
'Изменить' внести актуальный статус.
3. Сотрудники могут при необходимости вывести данные в Excel формат для редактирования/печати.

Запуск приложения:
1) Скопировать репозиторий из GitHub
2) Перейти в папку с проектом
3) Настроить переменные окружения:
cp .env.example .env
4) Запустить приложение используя Docker:
docker-compose up -d --build
5) Выполнить миграции:
docker-compose exec status python manage.py migrate

Переход на страницу:
1) Главная страница -  http://localhost:8000/main/sogl/
2) Страница администратора -  http://localhost:8000/admin/

Деактивация приложения:
docker-compose down

Создание суперпользователя:
docker-compose exec status python manage.py createsuperuser

Запуск Unit-тестов:
docker-compose exec status python manage.py test Status
